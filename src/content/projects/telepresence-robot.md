**Role:** Designer, Developer, and team leader

**Client:** Human Media Interaction group

**Keywords:** human-robot interaction, concept development, prototyping, user evaluation

This project explored how facial expressivity could be added to a cost-constrained telepresence robot. I designed a modular interaction pipeline that captures the operator’s facial expressions using depth sensing, classifies them, and translates them into simplified expressions displayed on the robot itself.

![Visualization of the suggested pipeline](/assets/img/projects/GP/fotos/Interaction.png)

The work combined human-robot interaction, concept development, prototyping, machine learning, embedded hardware, and user evaluation.
